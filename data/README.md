# Data

Raw and processed datasets used in the experiments:

- **Communities & Crime** — UCI Machine Learning Repository
- **Lending Club loans** — Kaggle (`wordsforthewise/lending-club`)
- **NHANES 2013–2014** — CDC via Kaggle (`cdc/national-health-and-nutrition-examination-survey`)

Put downloaded files under `data/raw/` and preprocessed outputs under `data/processed/`.
